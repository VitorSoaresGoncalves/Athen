## Tecnologias Utilizadas

### Front-end

* **React 19.2.8** — biblioteca utilizada para a construção da interface e dos componentes da aplicação.
* **TypeScript 6.0.2** — linguagem utilizada no desenvolvimento, fornecendo tipagem estática ao JavaScript.
* **Vite 8.2.2** — ferramenta utilizada para configuração, execução do ambiente de desenvolvimento e build da aplicação.
* **React DOM 19.2.8** — responsável pela integração dos componentes React com o DOM da aplicação.

### Banco de Dados e Backend

* **Supabase** — plataforma utilizada para hospedagem e gerenciamento do banco de dados da aplicação.
* **PostgreSQL** — sistema gerenciador de banco de dados relacional utilizado pelo Supabase para armazenamento e gerenciamento dos dados.

### Ferramentas de Desenvolvimento

* **ESLint 10.9.0** — utilizado para análise estática do código e identificação de possíveis problemas e inconsistências.
* **TypeScript ESLint 8.67.0** — integração entre TypeScript e ESLint para aplicação das regras de qualidade ao código TypeScript.
* **ESLint React Hooks 7.1.1** — regras de lint específicas para utilização dos React Hooks.
* **ESLint React Refresh 0.5.4** — suporte às verificações relacionadas ao React Fast Refresh durante o desenvolvimento.

### Bibliotecas e Tipagens

* **@types/node 24.13.3** — definições de tipos TypeScript para recursos do Node.js.
* **@types/react 19.2.18** — definições de tipos para o React.
* **@types/react-dom 19.2.4** — definições de tipos para o React DOM.
* **@vitejs/plugin-react 6.1.0** — integração do React com o Vite.
* **@eslint/js 10.0.1** — configurações e regras base do ESLint.
* **globals 17.11.0** — definições de variáveis globais utilizadas pelas configurações do ESLint.

### Resumo da Stack

**Frontend:** React + TypeScript + Vite
**Banco de Dados:** PostgreSQL
**Hospedagem do Banco:** Supabase
**Qualidade de Código:** ESLint + TypeScript ESLint
